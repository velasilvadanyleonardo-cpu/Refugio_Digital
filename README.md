# 🐾 Refugio Digital

Plataforma MVP diseñada para conectar animales en abandono o riesgo con adoptantes, refugios y padrinos.

## Características Principales
* **Adopción Rápida:** Galería optimizada de mascotas en busca de un hogar seguro.
* **Sistema de Reportes:** Formulario geo-referenciado para alertar sobre animales en la calle (100% gratuito).
* **Función Premium:** Sistema ético de suscripción mensual para apoyar financieramente el trabajo de los refugios.

## Tecnologías y Optimización
* **HTML5 Semántico:** Estructura limpia y accesible.
* **Tailwind CSS (CDN):** Interfaz moderna y 100% responsiva (Mobile-First) sin tiempos de compilación.
* **JavaScript (Vanilla):** Lógica sin dependencias, utilizando `DocumentFragment` para renderizado de alto rendimiento.
